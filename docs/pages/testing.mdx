Zener tests check connectivity, component properties, and circuit topology.
`TestBench` instantiates a module for each input case, then runs check functions
against the evaluated module.

## Write a test bench

In a [PCB workspace](/pages/quickstart), create `series.zen` with two resistors
in series:

```python
Resistor = Module("@stdlib/generics/Resistor.zen")

IN = io(Net)
OUT = io(Net)
MID = Net()

Resistor(name="R1", value="1k", package="0402", P1=IN, P2=MID)
Resistor(name="R2", value="2k", package="0402", P1=MID, P2=OUT)
```

Create `test_series.zen` beside it:

```python
Series = Module("./series.zen")

def resistor(expected_value):
    def matcher(path, cursor):
        check(cursor < len(path.components), "expected another resistor")
        component = path.components[cursor]
        check(component.type == "resistor", "expected a resistor")
        check(component.resistance.matches(expected_value), "unexpected resistance")
        return 1
    return matcher

def verify_series(module, inputs):
    components = module.components()
    check(len(components) == 2, "expected two components")
    check(components["R1.R"].resistance.matches("1k"), "R1 must be 1 kohm")
    check(len(module.nets()["TEST_IN"]) == 1, "unexpected input connection")

    paths = module.graph().paths(start="TEST_IN", end="TEST_OUT", max_depth=6)
    check(len(paths) == 1, "expected one series path")
    paths[0].matches(resistor("1k"), resistor("2k"))

TestBench(
    name="SeriesTest",
    module=Series,
    test_cases={"default": {"IN": Net("TEST_IN"), "OUT": Net("TEST_OUT")}},
    checks=[verify_series],
)
```

Run it with `pcb test test_series.zen`. Each check receives the evaluated module
and its case's input dictionary. `check(condition, message)`, `error(message)`,
and unhandled evaluation errors fail the test with a source location.

`test_cases` must be a nonempty map of case names to module input dictionaries.
Supply all required `io()` and `config()` inputs; modules without required
inputs can use an empty dictionary for a case.

## Inspect the evaluated module

| Expression | Result |
|---|---|
| `module.nets()` | Map from net names to connected `(component_path, pin)` tuples. |
| `module.components()` | Map from module-relative hierarchical paths to components. |
| `module.components()["R1.R"]` | The physical resistor inside generic module `R1`. |
| `module.graph()` | Circuit graph for path searches. |

Call `nets()` and `components()` before accessing their dictionaries; the module
itself does not support `[]`. Component values expose `name`, `type`, `pins`,
`properties`, sourcing fields, and component-specific properties such as
`resistance`.

## Search and match paths

`graph.paths(start=..., end=..., max_depth=...)` finds simple paths between
public `io()` net names or `(component_path, pin)` tuples. Tuple paths use the
graph's full component paths, as returned in a path's `ports`. `max_depth`
bounds the path's port count, not its component count; omitting it leaves the
search unbounded. Set it explicitly for large circuits.

Each path exposes `ports`, `components`, and `nets`. To test individual
components, use a check function that succeeds by returning without an error:

```python
def is_resistor(component):
    check(component.type == "resistor", "expected a resistor")
```

| Method | Behavior |
|---|---|
| `path.count(is_resistor)` | Count matching components. |
| `path.any(is_resistor)` | Fail unless at least one matches. |
| `path.all(is_resistor)` | Fail unless every component matches. |
| `path.none(is_resistor)` | Fail if any component matches. |

For ordered topology checks, `path.matches()` calls each matcher with the path
and current component index. A matcher returns the number of components it
consumed; the sequence must consume the entire path. The `resistor()` factory
above is a project-defined helper, not a prelude symbol.

When searching among candidate paths, use `suppress_errors=True` to return
`False` for a sequence mismatch instead of failing the test:

```python
matching_paths = [path for path in paths if path.matches(
    resistor("1k"), resistor("2k"), suppress_errors=True,
)]
check(len(matching_paths) > 0, "expected a 1k/2k series path")
```
